# 川島地区 農地調査マップ(Leaflet + GitHub Pages)

サーバー不要の閲覧専用WebGISです。`data/` の2ファイルを差し替えるだけで地図が更新されます。

## フォルダ構成

```
index.html               地図本体(冒頭の CONFIG だけ編集すればOK)
data/fields.geojson      筆ポリゴン(1,566筆、fid・地目のみに軽量化)
data/survey.csv          調査記録(Streamlit版のスプレッドシートを書き出したもの)
tools/prepare_data.py    上の2ファイルを作るスクリプト
tiles/                   (任意)UAVオルソなどのXYZタイル
```

## 地図でできること

- 筆ポリゴンを、最新調査の「作付状況」で色分け(未調査は黄色の枠線のみ)
- クリックで、地目(田/畑)・最新の調査結果・調査履歴を右パネルに表示
- 凡例のチェックで区分ごとに表示/非表示(例:耕作放棄だけ表示)
- 「作目・備考で絞込」に「キャベツ」「サル」などと入れると、該当筆だけ表示
- fid検索、現在地表示(スマホで現地確認用)、背景地図の切替

## データの更新方法

### 方法1:CSVを書き出してアップロード(現在の方式)

1. Googleスプレッドシートを「ファイル → ダウンロード → CSV」で保存
2. 次のコマンドで整形(Python標準ライブラリのみで動作)
   ```
   python tools/prepare_data.py kawashima2026p.geojson 書き出したCSV.csv
   ```
3. できた `data/survey.csv` をGitHubに上書きアップロード

筆ポリゴンが変わらなければ、2回目以降は `data/survey.csv` だけの更新で済みます。

### 方法2:スプレッドシートを直接読む(更新作業が不要になる)

1. スプレッドシートで「ファイル → 共有 → ウェブに公開」→ 対象シート・形式「CSV」→ 公開
2. 表示されたURLを `index.html` の `CONFIG.survey` に貼り付ける

以後は、スプレッドシートに記録が追加されるたびに、地図の「再読み込み」で反映されます。
ただし、公開したCSVはURLを知っている人なら誰でも見られます。備考に個人が特定できる内容がないか確認してください。
列名(fid・調査日・作付状況・作目・調査者・備考・タイムスタンプ)は現在のシートと同じままにしてください。

## UAVオルソを重ねる(任意)

1. QGISのプロセッシング →「XYZタイルを生成(ディレクトリ)」
2. ズーム最小14〜最大19または20、形式JPG(NDVIなど透過が必要ならPNG)、出力先 `tiles/ortho202607/`
3. `index.html` の `CONFIG.overlays` のコメントを外し、パスを合わせる

GitHubは1ファイル100MBまで、サイト全体は1GB程度が目安です。最大ズームを1段下げると容量は約1/4になります。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成(Public)
2. 「Add file」→「Upload files」で、このフォルダの中身をドラッグ&ドロップ →「Commit changes」
3. 「Settings」→「Pages」→ Branch: `main` / `/(root)` →「Save」
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で閲覧できます

## ローカルで確認する場合

`index.html` をダブルクリックして開いても、データは表示されません(ブラウザの制限)。
このフォルダで次のコマンドを実行し、`http://localhost:8000` を開きます。

```
python -m http.server 8000
```
